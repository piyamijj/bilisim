# AI Etkisi — Yapay Zekânın Dünyayı Değiştiren Gücü

Sağlık, eğitim, tarım, finans ve daha birçok alanda yapay zekânın etkilerini
görsel ve etkileşimli olarak anlatan Next.js platformu (Türkçe).

## Teknolojiler

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS, Framer Motion
- Recharts + Chart.js grafikleri
- Açık/koyu tema desteği

## Geliştirme

```bash
npm install
npm run dev
```

## Derleme

```bash
npm run build
npm start
```

## Deploy

Vercel'e bağlıdır; `master` dalına push edildiğinde otomatik deploy olur.
